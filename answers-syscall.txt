What is the value of p->trapframe->a7 and what does that value represent? 
(Hint: look at user/init.c, the first user program xv6 starts, and its compiled assembly user/init.asm.)

    It is the system call number requested by the user process e.g. in user/init.asm, before each `ecall` instruction, the a7 register is set to a specific value using `li a7, SYS_x` where x can be open, exec, kill etc. 
    This value tells the kernel which system call to execute (e.g. fork, exit, wait, etc.)

What was the previous mode that the CPU was in?

    The value of sstatus is 0x200000022. The SPP bit in sstatus indicates the previous mode. 
    If SPP is set (bit 8), the previous mode was supervisor; if it is clear, the previous mode was user. (clarification for personal understanding)
    Here, SPP is clear, so the previous mode was user mode.

    The kernel crashes because it tries to read from address 0, which is not mapped in the kernel's virtual address space.
