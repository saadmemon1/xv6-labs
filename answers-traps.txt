Which registers contain arguments to functions? For example, which register holds 13 in main's call to printf?
Register a2 holds the value 13 in main's call to printf. Generally, registers a0-a7 contain arguments to functions. a1 holds 12 (f(8) + 1) and a0 holds the format string pointer


Where is the call to function f in the assembly code for main? Where is the call to g? (Hint: the compiler may inline functions.)
f(8) is called in main function at compile time. It further calls g(8) which returns 8+3=11 (x+3). The compiler inlined them, directly computing without any explicit calls to these functions.


At what address is the function printf located?
0x73e. The jal instruction (jal	73e <printf>) jumps to the target address 73e, which is where the printf function code begins.


What value is in the register ra just after the jalr to printf in main?
0x3c. Since the jal instruction is at address 0x38, the next instruction is at 0x38 + 4 = 0x3c. This address (0x3c) is saved in ra so that when printf returns, it knows where to continue execution in main.


Run the following code.

	unsigned int i = 0x00646c72;
	printf("H%x Wo%s", 57616, (char *) &i);
      
What is the output?
He110 World
The output depends on that fact that the RISC-V is little-endian. If the RISC-V were instead big-endian what would you set i to in order to yield the same output? Would you need to change 57616 to a different value?
i = 0x726c6400. 57616 does not need to be modified.


In the following code, what is going to be printed after 'y='? (note: the answer is not a specific value.) Why does this happen?

	printf("x=%d y=%d", 3);
After 'y=' will be printed whatever garbage/undefined value happens to be in register a2. This happens because printf was called with only one argument (3) when it requires two arguments. It reads from a2 anyway, getting whatever random value is there.
